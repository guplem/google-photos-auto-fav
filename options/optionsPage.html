Google Photos auto Fav

The run

Open an album, press Start in the panel at the bottom left, and the extension walks the album and marks every photo whose file name is in your list.

Speed and safety

The extension reads the file name and the favourite button after each move. Both belong to the previous photo for a moment. These numbers decide how long it waits before it believes what it reads. Raise them on a slow connection. A photo the extension could not read is skipped and listed in the report, never marked by a guess.

Button names

The extension finds the favourite button by the name a screen reader would announce. Google Photos writes that name in your own language and can rename it. Put one name per line. Use Copy report in the panel to see the names Google Photos actually shows you, under page_now.toolbarControlNames.

Stored data

The list of file names stays on this computer, in the extension's own storage. Nothing is sent anywhere.
